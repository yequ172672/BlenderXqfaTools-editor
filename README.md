# XqfaTools - Blender 综合工具集

> 作者: xqfa | Blender 4.5+ | 版本: 2.0.0

一款面向游戏模型编辑流程的 Blender 插件，集成骨骼操作、网格属性管理、材质工具、映射转换和综合整理等功能。

## 安装

1. 下载本仓库
2. 在 Blender 中 `Edit > Preferences > Add-ons > Install`，选择本文件夹
3. 启用 **XqfaTools** 插件

插件偏好设置中可配置 `texconv.exe` 路径（用于 DDS 格式转换）。

## 功能概览

插件在 3D 视图侧栏（N 面板）提供 **XQFA** 分类，包含 5 个主标签页：

---

### 骨骼工具 (Bone Tools)

**骨骼与顶点组**
- **合并到父级/活动骨骼** — 选中骨骼权重合并到父级或活动骨骼，并删除源骨骼
- **顶点组合并到父级/活动** — 仅合并顶点组权重，保留骨骼
- **清理骨骼/顶点组** — 删除无对应顶点组的骨骼，或删除无对应骨骼的顶点组
- **添加/移除骨骼编号** — 为有权重骨骼批量添加 `b001:` 格式编号前缀

**姿态模式**
- **坐标系摆正** — Y-Up (90,0,0) / Z-Up (0,0,0) / 自动摆正至最近正交方向
- **绕轴旋转 90°** — 绕 X/Y/Z 轴旋转选中骨骼
- **应用骨架和姿态** — 一键应用骨骼修改器 + 姿态，保留骨架绑定
- **交换姿态和静置** — 交换骨骼的姿态位置与静置位置
- **CSV 导入选择骨骼** — 从 CSV 文件批量选择骨骼
- **复制选中骨骼名称** — 复制到剪贴板
- **解除所有锁定 / 去除所有约束**
- **移动到活动骨骼** — 支持 X/Y/Z 轴分量控制
- **父级转向活动骨骼** — 阻尼追踪约束或绕特定轴向旋转
- **父级缩放到活动骨骼** — 全局/局部坐标系缩放
- **骨骼矩阵显示** — 查看位置、欧拉旋转、四元数、4x4 矩阵

**编辑模式**
- 坐标系摆正、绕轴旋转 90°
- **选中/所有取消相连** — 批量设置 `use_connect = False`
- **尾部对齐子级** — 将骨骼尾部移动到子级头部平均位置；无子级时继承父级矩阵
- **摆正扭转** — 调整骨骼 roll 使 X 轴与全局 XY 平面平行

**MOD 骨架替换**
- 导入 CSV 映射表，执行骨骼简化、位置复制、重命名换绑
- 支持主骨骼/保留骨骼/指定骨骼映射列配置

---

### 属性工具 (Attribute Tools)

**顶点组**
- **统计** — 显示总数 / 有权重 / 无权重组数量
- **删除无权重顶点组** — 活动物体或批量选择物体
- **匹配重命名** — 基于顶点加权平均位置，用参考模型的顶点组名重命名目标模型
- **按名称排序** — 严格按参考物体的顶点组顺序重排目标物体

**形态键**
- **匹配重命名** — 基于形态键顶点平均位置匹配命名
- **按名称排序** — 严格按参考物体顺序重排形态键，缺少的自动补空键
- **顺序重命名** — 按参考物体形态键顺序依次重命名
- **选中影响顶点** — 选中当前形态键与基础形态键有差异的顶点
- **传递形态键** — 将源物体形态键传递给目标物体（需顶点数一致）

**UV 贴图**
- 设置活动/渲染 UV 层索引、删除指定索引 UV、覆盖重命名为 `TEXCOORD.xy` 格式

**顶点色**
- 设置活动/渲染颜色属性、删除指定索引、添加并重命名序列为 `COLOR/COLOR1/COLOR2...`
- **转换属性类型** — 在 Point/Corner 域和 Float/Byte 类型间转换
- **调色板工具** — 添加/删除/应用颜色到选中物体活动顶点色层

**额外物体信息**
- 左下角实时显示当前顶点组和形态键名称/总数
- 3D 视图和 UV 编辑器中显示选中顶点的顶点 ID 和面拐 ID
- **复制选中顶点 ID** — 支持逗号/换行/空格/Python 列表格式

### 其他工具 (Other Tools)

- **创建空模** — 创建极小平面并分配到两个指定权重的顶点组
- **重命名 C→Components** — 将 `C0-body` 格式重命名为 `Component 0.-body`
- **应用为形态键** — 将骨架姿态保存为目标物体的形态键
- **按材质分离** — 支持材质名或原名_材质名 命名方式
- **平滑法线八面体 UV** — 计算切线空间平滑法线，投射八面体展开存储到 TEXCOORD1
- **数字顶点组 ↔ 骨骼名称** — 一键执行：清除材质→分配→合并→匹配重命名→排序→按材质分离→添加骨架→匹配材质
- **选择连线 >4 / <4 的顶点** — 编辑模式拓扑选择
- **选择 X<0 的顶点** — 空间位置选择
- **还原三角面中点细分** — 融并细分产生的顶点恢复四边面
- **选择对象及全部子级** — 递归选择含隐藏对象

---

### 映射工具 (Mapping Tools)

**顶点组重命名工具** (by 0w0-Yui)
- 权重绘制模式下交互式将顶点组名指定为骨骼名
- 支持预设保存/加载、合并已有顶点组、移除空/未使用顶点组、自动合并材质
- 可导出映射列表到骨骼工具的 CSV 数据

**ABP 生成器**
- 根据映射列表生成 UE4/5 Animation Blueprint 约束节点文本
- 支持自定义 ABP 资产路径，生成后自动复制到剪贴板

---

### 综合工具 (General Tools)

**通用工具**
- 删除无材质球的模型
- 按材质球重命名模型
- 删除无图片节点的模型
- 重命名后清理重复模型
- 从选中中删除相同模型
- 节点复制到最前面的模型

**材质工具**
- 选同贴图模型 / 选同材质模型
- 恢复原始材质（去 .00x 后缀）
- 根据图片尺寸重命名材质球
- MMD 材质一键转 Principled BSDF
- 清理重复贴图节点
- 连接基础色/金属度/粗糙度
- 连接自发光 + 透贴
- 常规一键连法线

**编辑模式工具**
- 顶点环减面 — 将选中顶点环合并到指定数量

**姿态/骨架工具**
- 高级姿态镜像 — 支持局部旋转/世界原点/轴向翻转三种方案，可配置左右标识符

---

### 材质编辑器工具 (Node Editor)

- **新建 3 贴图材质** — 快速创建 BaseColor/Metallic/Roughness 贴图节点
- **创建已打包图像** — 在光标位置创建打包的图像纹理节点
- **深度法线分析 (Sobel)** — 基于 Sobel 算子诊断法线贴图是 OpenGL (Y+) 还是 DirectX (Y-)
- **批量创建材质** — 为所有无材质物体创建同名材质
- **节点组烘焙** — 批量烘焙节点组输出到贴图，支持通道打包（RGBA 自由组合）和 DDS 格式转换
- **材质连接快照** — 拍摄/恢复/删除材质节点连接状态快照
- **材质批量重命名** — 查找替换、添加前缀后缀、全选/反选操作

```

├── panel.py                 # 主面板 UI（标签页切换）
├── bone_tools/
│   ├── bone_and_vertex_groups.py  # 骨骼与顶点组操作
│   ├── bone_pose.py              # 姿态模式工具
│   ├── bone_edit.py              # 编辑模式工具
│   └── mod_armature_replace.py   # MOD 骨架替换（CSV 驱动）
├── attribute_tools/
│   ├── vertex_groups.py     # 顶点组管理
│   ├── shapekey.py          # 形态键管理
│   ├── uv.py                # UV 贴图管理
│   ├── vertex_colors.py     # 顶点色管理
│   └── extra_object_info.py # 物体信息叠加显示
├── material_tools/
│   ├── material.py              # 材质基础工具
│   ├── bake_node_groups.py      # 节点组烘焙 + 通道打包
│   ├── material_snapshot.py     # 材质连接快照
│   └── material_batch_rename.py # 材质批量重命名
├── mapping_tools/
│   ├── modtoolkit.py        # 顶点组重命名工具（by 0w0-Yui）
│   └── abp_generator.py     # UE4/5 ABP 约束节点生成器
├── general_tools/
│   └── y_tools.py           # 综合整理工具集
└── other_tools/
    ├── misc.py              # 杂项工具
    └── texconv.exe          # DDS 格式转换工具
```
